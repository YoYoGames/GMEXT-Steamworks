Parties¶

Steamworks Interface: ISteamParties

This API can be used to selectively advertise your multiplayer game session in a Steam chat room group. Tell Steam the number of player spots that are available for your party, and a join-game string, and it will show a beacon in the selected group and allow that many users to "follow" the beacon to your party. Adjust the number of open slots if other players join through alternate matchmaking methods.

steam_parties_set_callback_reservation_notification¶

Steamworks Function: N / A

This function sets the function to be called by Steam when a user "follows" a previously created beacon. This lets you know that you should be prepared for the user to join your game.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

steam_parties_set_callback_reservation_notification(callback)
Argument Type Description
callback Function The function to be called when a reservation notification event occurs.


Returns:

N/A


Triggers:

Callback

Steamworks Callback: ISteamParties::ReservationNotificationCallback_t

Called when a user "follows" a beacon that the current user created.

Key Type Description
result SteamPartiesReservationNotification The details of the reservation.

steam_parties_create_beacon¶

Steamworks Function: ISteamParties::CreateBeacon

This function creates a beacon. You can only create one beacon at a time. Steam will display the beacon in the specified location, and let up to open_slots users "follow" the beacon to your party.

If users join your party through other matchmaking, adjust the number of remaining open slots using steam_parties_change_num_open_slots.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

steam_parties_create_beacon(open_slots, beacon_location_type, beacon_location_id, connect_string, metadata, callback)
Argument Type Description
open_slots Real The number of reservation slots to create for the beacon, normally the party size minus one.
beacon_location_type SteamPartiesBeaconLocationType The type of the beacon location, taken from one of the locations returned by steam_parties_get_available_beacon_locations.
beacon_location_id Real The location ID of the beacon location, taken from one of the locations returned by steam_parties_get_available_beacon_locations.
connect_string String The connect string that will be given to the game on launch for a user that follows the beacon.
metadata String Additional game metadata that can be set on the beacon, and is exposed via steam_parties_get_beacon_details.
callback Function The function to call upon completion.


Returns:

Boolean


Triggers:

Callback

Steamworks Callback: ISteamParties::CreateBeaconCallback_t

This callback is returned as the response to a call to create a beacon. A successful result means your beacon has been posted in the desired location and you can begin receiving reservation notifications as users follow it.

Key Type Description
result SteamPartiesCreateBeaconResult The result of the operation.

steam_parties_destroy_beacon¶

Steamworks Function: ISteamParties::DestroyBeacon

This function destroys the Steam party beacon. This will immediately cause Steam to stop showing the beacon in the target location. Note that any users currently in-flight may still arrive at your party expecting to join.

Your game should call this method when either the party has been filled and the game is beginning, or the user has decided to abandon creating a party. The beacon will be destroyed automatically when your game exits, but the preferred behaviour is for the game to call steam_parties_destroy_beacon at the right time.


Syntax:

steam_parties_destroy_beacon(beacon_id)
Argument Type Description
beacon_id Real The beacon ID to be destroyed.


Returns:

Boolean

steam_parties_join_party¶

Steamworks Function: ISteamParties::JoinParty

This function is called when the user indicates they wish to join the party advertised by a given beacon. On success, Steam will reserve a slot for this user in the party and return the necessary "join game" string to use to complete the connection.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

steam_parties_join_party(beacon_id, callback)
Argument Type Description
beacon_id Real The beacon ID for the party you wish to join.
callback Function The function to call upon completion.


Returns:

Boolean


Triggers:

Callback

Steamworks Callback: ISteamParties::JoinPartyCallback_t

This callback serves as the response to a call to join a party. When it succeeds, you have secured a slot in the beacon owner's party and should use the connect string to link up with their game and finish joining.

Key Type Description
result SteamPartiesJoinPartyResult The result of the operation.
