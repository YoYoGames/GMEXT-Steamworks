Remote Storage

Steamworks Interface: ISteamRemoteStorage

This module provides functions for reading, writing, and accessing files which can be stored remotely in the Steam Cloud.

See Steam Cloud for more information.

steam_remote_storage_file_write

Steamworks Function: ISteamRemoteStorage::FileWrite

This function creates a new file, writes the bytes to the file, and then closes the file. If the target file already exists, it is overwritten.

Note

This is a synchronous call and as such is a will block your calling thread on the disk IO, and will also block the SteamAPI, which can cause other threads in your application to block. To avoid "hitching" due to a busy disk on the client machine using steam_remote_storage_file_write_async, the asynchronous version of this API is recommended.


Syntax:

steam_remote_storage_file_write(file_name, data, buffer_offset=undefined, buffer_count=undefined)
Argument Type Description
file_name String The name of the file to write to.
data Buffer The buffer containing the bytes to write to the file.
buffer_offset Real The offset into the buffer, in bytes. Defaults to 0.
buffer_count Real The number of bytes to write, starting at the offset. Defaults to the buffer size minus the offset.


Returns:

Boolean

steam_remote_storage_file_write_async

Steamworks Function: ISteamRemoteStorage::FileWriteAsync

This function creates a new file and asynchronously writes the raw byte data to the Steam Cloud, and then closes the file. If the target file already exists, it is overwritten.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

steam_remote_storage_file_write_async(file_name, data, callback, buffer_offset=undefined, buffer_count=undefined)
Argument Type Description
file_name String The name of the file to write to.
data Buffer The buffer holding the bytes to write to the file.
callback Function The callback function to call upon completion.
buffer_offset Real The offset into the buffer, in bytes. Defaults to 0.
buffer_count Real The number of bytes to write. Defaults to the buffer size minus the offset.


Returns:

N/A


Triggers:

Callback

Steamworks Callback: ISteamRemoteStorage::RemoteStorageFileWriteAsyncComplete_t

Key Type Description
result SteamRemoteStorageFileWriteAsyncResult The result of the operation.

steam_remote_storage_file_delete

Steamworks Function: ISteamRemoteStorage::FileDelete

This function deletes a file from the local disk, and propagates that delete to the cloud.

This is meant to be used when a user actively deletes a file. Use steam_remote_storage_file_forget if you want to remove a file from the Steam Cloud but retain it on the user's local disk.

When a file has been deleted it can be re-written with steam_remote_storage_file_write to reupload it to the Steam Cloud.


Syntax:

steam_remote_storage_file_delete(file_name)
Argument Type Description
file_name String The name of the file that will be deleted.


Returns:

Boolean

true if the file exists and has been successfully deleted; otherwise, false if the file did not exist.

steam_remote_storage_file_forget

Steamworks Function: ISteamRemoteStorage::FileForget

This function deletes the file from remote storage, but leaves it on the local disk and remains accessible from the API.

When you are out of Cloud space, this can be used to allow calls to steam_remote_storage_file_write to keep working without needing to make the user delete files.

How you decide which files to forget are up to you. It could be a simple Least Recently Used (LRU) queue or something more complicated.

Requiring the user to manage their Cloud-ised files for a game, while is possible to do, it is never recommended. For instance, "Which file would you like to delete so that you may store this new one?" removes a significant advantage of using the Cloud in the first place: its transparency.

Once a file has been deleted or forgotten, calling steam_remote_storage_file_write will resynchronise it in the Cloud. Rewriting a forgotten file is the only way to make it persisted again.


Syntax:

steam_remote_storage_file_forget(file_name)
Argument Type Description
file_name String The name of the file that will be forgotten.


Returns:

Boolean

steam_remote_storage_file_write_stream_open

Steamworks Function: ISteamRemoteStorage::FileWriteStreamOpen

This function creates a new file output stream allowing you to stream out data to the Steam Cloud file in chunks. If the target file already exists, it is not overwritten until steam_remote_storage_file_write_stream_close has been called.

To write data out to this stream you can use steam_remote_storage_file_write_stream_write_chunk, and then to close or cancel you use steam_remote_storage_file_write_stream_close and steam_remote_storage_file_write_stream_cancel respectively.


Syntax:

steam_remote_storage_file_write_stream_open(file_name)
Argument Type Description
file_name String The name of the file to write to.


Returns:

Real

The file write stream handle, or STEAM_REMOTE_STORAGE_UGC_FILE_STREAM_HANDLE_INVALID in case the stream couldn't be opened
