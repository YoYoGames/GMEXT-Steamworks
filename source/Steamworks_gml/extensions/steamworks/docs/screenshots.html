steam_screenshots_add_screenshot_to_library

Steamworks Function: ISteamScreenshots::AddScreenshotToLibrary

This function adds a screenshot to the user's Steam screenshot library from disk.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

steam_screenshots_add_screenshot_to_library(filename, thumbnail_filename, width, height)
Argument Type Description
filename String The absolute file path to the JPG, PNG, or TGA screenshot.
thumbnail_filename String The absolute file path to an optional thumbnail image. This must be 200px wide, as described by k_ScreenshotThumbWidth and the same aspect ratio. Pass an empty string "" if there is no thumbnail, one will be created automatically.
width Real The width of the screenshot.
height Real The height of the screenshot.


Returns:

Real

Screenshot handle, or STEAM_SCREENSHOTS_INVALID_SCREENSHOT_HANDLE if the file could not be saved (See: macros)


Triggers:

Callback

Steamworks Callback: ISteamScreenshots::ScreenshotReady_t

This is triggered when a screenshot has been successfully written or otherwise added to the library and can now be tagged.

Key Type Description
result SteamScreenshotsScreenshotReady The result of the operation.

steam_screenshots_hook_screenshots

Steamworks Function: ISteamScreenshots::HookScreenshots

This function toggles whether the overlay handles screenshots when the user presses the screenshot hotkey, or if the game handles them.

Hooking is disabled by default, and only ever enabled if you do so with this function.

If the hooking is enabled, then the ScreenshotRequested_t callback will be sent if the user presses the hotkey or when steam_screenshots_trigger_screenshot is called, and then the game is expected to call steam_screenshots_write_screenshot or steam_screenshots_add_screenshot_to_library in response.

You can check if hooking is enabled with steam_screenshots_is_screenshots_hooked.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

steam_screenshots_hook_screenshots(hook)
Argument Type Description
hook Boolean Enable (true) or disable (false) hooking?


Returns:

N/A


Triggers:

Callback

Steamworks Callback: ISteamScreenshots::ScreenshotRequested_t

Triggered when a screenshot has been requested by the user from the Steam screenshot hotkey. This will only be called if steam_screenshots_hook_screenshots has been enabled, in which case Steam will not take the screenshot itself.

This callback has no fields.

steam_screenshots_set_location

Steamworks Function: ISteamScreenshots::SetLocation

This function sets optional metadata about a screenshot's location. For example, the name of the map it was taken on.

You can get the handle to tag the screenshot once it has been successfully saved from the ScreenshotReady_t callback or via the steam_screenshots_write_screenshot, steam_screenshots_add_screenshot_to_library, steam_screenshots_add_vr_screenshot_to_library calls.


Syntax:

steam_screenshots_set_location(screenshot, location)
Argument Type Description
screenshot Real The handle to the screenshot to tag.
location String The location in the game where this screenshot was taken. This can not be longer than STEAM_SCREENSHOTS_UFS_TAG_VALUE_MAX.


Returns:

Boolean

true if the location was successfully added to the screenshot. false if the screenshot handle was invalid, or the location is invalid or too long.

steam_screenshots_tag_published_file

Steamworks Function: ISteamScreenshots::TagPublishedFile

This function tags a published file as being visible in the screenshot.

You can tag up to the value declared by STEAM_SCREENSHOTS_MAX_TAGGED_USERS (k_nScreenshotMaxTaggedPublishedFiles) in a single screenshot. Tagging more items than that will just be discarded.

This function has a built-in delay before saving the tag which allows you to call it repeatedly for each item.

You can get the handle to tag the screenshot once it has been successfully saved from the ScreenshotReady_t callback or via the steam_screenshots_write_screenshot, steam_screenshots_add_screenshot_to_library, steam_screenshots_add_vr_screenshot_to_library calls.


Syntax:

steam_screenshots_tag_published_file(screenshot, published_file_id)
Argument Type Description
screenshot Real The handle to the screenshot to tag.
published_file_id Real The workshop item ID that is in the screenshot.


Returns:

Boolean

steam_screenshots_write_screenshot

Steamworks Function: ISteamScreenshots::WriteScreenshot

This function writes a screenshot to the user's Steam screenshot library given the raw image data, which must be in RGB format.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

steam_screenshots_write_screenshot(buff_rgb, width, height, buffer_offset=undefined, buffer_count=undefined)
Argument Type Description
buff_rgb Buffer The buffer containing the raw RGB data from the screenshot.
width Real The width of the screenshot in pixels.
height Real The height of the screenshot in pixels.
buffer_offset Real The offset into the buffer, in bytes. Defaults to 0.
buffer_count Real The number of bytes to write. Defaults to the buffer size minus the offset.


Returns:

Real

Screenshot handle, or STEAM_SCREENSHOTS_INVALID_SCREENSHOT_HANDLE if the file could not be saved


Triggers:

Callback

Steamworks Callback: ISteamScreenshots::ScreenshotReady_t

This is triggered when a screenshot has been successfully written or otherwise added to the library and can now be tagged.

Key Type Description
result SteamScreenshotsScreenshotReady The result of the operation.

SteamScreenshotsScreenshotReady

Steamworks Struct: ISteamScreenshots::ScreenshotReady_t

This struct holds information received when a screenshot has been successfully written or otherwise added to the library and can now be tagged.

This struct is referenced by the following functions:

  • steam_screenshots_add_screenshot_to_library
  • steam_screenshots_add_vr_screenshot_to_library
  • steam_screenshots_trigger_screenshot
  • steam_screenshots_write_screenshot


Member Type Description
screenshot_handle Real The screenshot handle that has been written.
result SteamApiResult The result of the operation. Possible values:

SteamApiResult.Ok - The screenshot was successfully added to the user's library.
 SteamApiResult.Fail - The screenshot could not be loaded or parsed.
* SteamApiResult.IoFailure - The screenshot could not be saved to the disk.
