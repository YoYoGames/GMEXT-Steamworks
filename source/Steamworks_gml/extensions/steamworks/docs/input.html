Input¶

Steamworks Interface: ISteamInput

This module contains Steam Input functionality. Steam Input API is a flexible action-based API that supports all major controller types - Xbox, PlayStation, Nintendo Switch Pro, and Steam Controllers.

See the Steam Input documentation for more information.

steam_input_activate_action_set¶

Steamworks Function: ISteamInput::ActivateActionSet

This function reconfigures the controller to use the specified action set (i.e. "Menu", "Walk", or "Drive").

This is cheap, and can be safely called repeatedly. It's often easier to repeatedly call it in your state loops, instead of trying to place it in all of your state transitions.


Syntax:

steam_input_activate_action_set(input_handle, action_set_handle)
Argument Type Description
input_handle Real The handle of the controller you want to activate an action set for.
action_set_handle Real The handle of the action set you want to activate.


Returns:

N/A

steam_input_get_gamepad_index_for_controller¶

Steamworks Function: ISteamInput::GetGamepadIndexForController

This function returns the XInput slot Steam Input presents the given controller to the game as, or -1 when the controller has none. A slot is only assigned while Steam Input is handling the controller and emulating an Xbox controller for it, which is the case when Steam Input is enabled for your game in the user's Steam controller settings (or in your game's Steamworks settings). A controller the game reads directly - Steam Input disabled, or a device Steam Input does not emulate - always returns -1, even though its handle is valid for every other Steam Input function. The slot maps to the index the GameMaker gamepad_* functions use on Windows.


Syntax:

steam_input_get_gamepad_index_for_controller(input_handle)
Argument Type Description
input_handle Real The handle of the controller you want to get a gamepad index for.


Returns:

Real

The XInput slot of the controller, or -1 if it has none.

SteamInputControllerSourceMode¶

Steamworks Enum: ISteamInput::EControllerSourceMode

This enum's members describe the virtual input mode imposed by the configurator upon a controller source. For instance, the configurator can make an analog joystick behave like a Dpad with four digital inputs; the controller source would be SteamInputControllerSource.Joystick and the controller source mode would be SteamInputControllerSourceMode.Dpad. The mode also changes the input data received by any associated actions.

These constants are referenced by the following structs:

  • SteamInputAnalogActionData


Member Description
None No input mode.
Dpad A digital pad -- four digital directional buttons fused together in a cross pattern, such that only one button from each axis can be pressed at any given time.
Buttons Buttons.
FourButtons Four digital face buttons, any of which can be pressed simultaneously.
AbsoluteMouse AbsoluteMouse.
RelativeMouse RelativeMouse.
JoystickMove JoystickMove.
JoystickMouse JoystickMouse.
JoystickCamera JoystickCamera.
ScrollWheel ScrollWheel.
Trigger Trigger.
TouchMenu TouchMenu.

Member Type Description
mode SteamInputControllerSourceMode The type of data coming from this action, this will match what was specified in the action set's VDF definition.
